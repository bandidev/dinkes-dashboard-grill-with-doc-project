# Domain Docs

This is a single-context repository.

Before domain work, read the root `CONTEXT.md` and relevant ADRs under `docs/adr/`. If ADRs do not exist, proceed without creating them. Use glossary terms in issues, tests, and implementation notes; avoid synonyms marked “Avoid”.

If a decision contradicts an existing ADR, call out the conflict. Record a genuinely new domain term or decision through `/domain-modeling` when needed.
