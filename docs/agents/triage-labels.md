# Triage Labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Awaiting evaluation |
| `needs-info` | `needs-info` | Awaiting reporter details |
| `ready-for-agent` | `ready-for-agent` | Specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

Use the GitHub label mapped to the role named by a skill. Edit the right column if this repository's label vocabulary changes.
